PreViral local benchmark media

This directory is for optional, locally supplied real benchmark Reels. Its contents are ignored by Git except this documentation and the example manifest.

Rules:

- Do not add personal, private, or third-party copyrighted videos to Git.
- Put local media only under this directory.
- Copy manifest.example.json to manifest.local.json and reference files with repository-relative paths under tests/media/local-benchmarks/.
- Keep manifest.local.json local; it is ignored.
- Synthetic fixtures should be generated by tests and use generated: locators instead of media downloads.
- The benchmark harness does not fetch remote media URLs.
- Label every fixture with its language and whether it is a creative exception; failed fixtures remain in benchmark denominators.
- Adapter manifests record runtime/model revisions, checksums, licenses, asset bytes, and delivery mode. Candidate adapters do not supply their own correctness scores.

The manifest schema is ../benchmark-manifest.schema.json.
